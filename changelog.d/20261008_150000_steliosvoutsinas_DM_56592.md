### Added

- Support table uploads on the BigQuery backend. Uploaded tables are written to GCS with a BigQuery schema and loaded by the worker into the dataset set by `tap.bigquery.upload.project` and `tap.bigquery.upload.dataset`.
- Add `gcs_upload_bucket` (or `GCS_UPLOAD_BUCKET`) to write uploaded tables to their own bucket. It defaults to the result bucket.
- Support a radius from a column or expression in BigQuery `CIRCLE`, e.g. `CIRCLE('ICRS', u.ra, u.dec, u.radius)`

### Changed

- Spatial queries on BigQuery only use `geo_point` for tables listed in `tap.bigquery.geoPointTables` (default `ppdb.DiaObject`). Other tables, including uploaded tables, build the point from their own columns.
